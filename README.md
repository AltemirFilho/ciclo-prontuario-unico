# Ciclo Prontuário Único

Trabalho da disciplina **Banco de Dados** (Ciência da Computação, UNIT, Aracaju/SE).
Professor: Sérgio Roberto Santos Santana.
Dupla: Altemir Cruz da Silva Filho e Juscelino Santos de Andrade.

**Tema:** prontuário espalhado na unidade de saúde.

Numa clínica com várias especialidades, a ficha do paciente fica na sala de quem atendeu por último. A fisioterapeuta não sabe da alergia que a médica anotou, a nutricionista não sabe do remédio novo, e cada setor guarda a própria versão do paciente. Nossa proposta é um banco de dados em que **um paciente tem um prontuário só**, escrito e lido por todas as especialidades, com regras que o próprio banco garante.

A base é a Ciclo, plataforma para profissionais de saúde que estamos construindo.

> Em construção durante a sprint de 24/11/2026. O andamento está no quadro e nas issues do repositório.

## Como rodar

```bash
npm install
npm run testes     # monta o banco e roda os 38 testes + os experimentos de índice
```
